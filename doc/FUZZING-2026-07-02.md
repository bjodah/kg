# Fuzzing Campaign 2026-07-02

## Scope

Ran the keypress libFuzzer target with 24 fork workers:

```sh
./test/fuzz_keypress -max_total_time=900 -fork=24 \
  -artifact_prefix=test/fuzz-artifacts/<run>/ test/fuzz-corpus/keypress
```

The campaign did not complete one uninterrupted 15 minute clean run.  Each
long run stopped early on a crash candidate, and the time was spent triaging
and fixing the low-hanging, reproducible findings.

## Fixed Findings

- `editor_del_forward_char()` read past EOL when rectangle mark mode left the
  cursor in virtual space.  Confirmed with PTY regression
  `test/pty/28-rect-virtual-forward-delete.yaml`.
- `editor_kill_line()` joined the next line from rectangle virtual space.
  Covered by `test/pty/29-rect-virtual-kill-line.yaml`.
- `editor_move_cursor(ARROW_LEFT)` could make `cy` negative when moving left at
  BOL from the top row of a scrolled viewport.  Covered by
  `test/pty/30-left-scroll-bol-previous-line.yaml`.
- `editor_reflow_paragraph()` deleted whitespace-only paragraphs, leaving later
  sentence movement with stale row state.  Covered by
  `test/pty/31-reflow-space-only-sentence-backward.yaml`.
- `editor_undo()` trusted stale split/join columns and could write past a
  shortened row.  Covered by `test_split_line_short_row` in
  `test/test_undo.c`.
- `editor_join_line()` read a stale row when the cursor row was outside the
  current buffer after row-replacing edits.

All crash artifacts collected during this session replay clean after the fixes.
