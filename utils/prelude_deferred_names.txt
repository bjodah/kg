# names no startup path needs, one per line, sorted.  This is the ONLY
# hand-maintained list the split (utils/embed_lisp_split.py) takes as
# input -- everything else (which bytes belong to which array, each
# name's offset and length) is derived mechanically from lisp/prelude.el
# itself, never duplicated by hand.
#
# Content: Phase 0.2's `--deferrable` census, reproduced with
#   make test/kgbatch
#   python3 utils/prelude_first_call_census.py --deferrable --json /tmp/c.json

# (macros are never wrapped and stay eager by construction) and none is
# order-sensitive (the alias-before-shadow scan finds exactly one
# order-sensitive name in the whole prelude, `internal--let`, which is
# not in this list).

# A name here MUST have a top-level `(defalias 'NAME (lambda ...))` form
# in lisp/prelude.el -- the split fails loudly otherwise, which is what
# keeps this list from silently drifting out of step with a rename.
#
