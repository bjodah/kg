## Fixed Findings

- Backspace joining after horizontal scrolling could leave stale negative
  scroll state and crash in `editor_del_char()`.  Covered by
  `test_backspace_join_long_previous_row_keeps_scroll_nonnegative` and
  `test/pty/33-backspace-join-long-line-repeat.yaml`.
- Paragraph and sentence movement trusted stale row/column state after edits.
  Covered by new word movement regressions in `test/test_word.c`.
- Normal insertion, autocomplete, mark setting, mark exchange, backspace, and
  raw newline insertion now clamp or saturate huge cursor offsets before using
  them as file positions.
- Rectangle-mode insertion now rejects absurd virtual padding gaps before they
  can request multi-gigabyte row allocations.
- Linear region kill/delete now deletes ranges in batches instead of one byte
  at a time, reducing slow-unit behavior on large regions.
- Repeated yank now records a length-only undo entry and inserts a bounded
  combined payload once, avoiding duplicate multi-megabyte undo allocations and
  repeated row updates.
- Transpose row replacement now allocates the replacement row array once rather
  than reallocating for every line.
- Right-arrow movement in rectangle virtual space now saturates horizontal
  scroll at `INT_MAX` instead of overflowing.
- Shared cursor helpers now normalize stale row/column offsets before edited
  commands convert screen coordinates to file positions.

All crash and OOM artifacts directly replayed during this session replay clean
after the corresponding fixes.
